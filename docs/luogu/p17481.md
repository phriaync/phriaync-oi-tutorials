# [P17481 平衡路线](https://www.luogu.com.cn/problem/P17481)

记 $ans=|n^+-n^-|$。若 $s,t$ 不连通，$ans=-1$。

以下假设 $s,t$ 连通，且只考虑其所在的连通块。

先判全 `+` 或全 `-`，此时 $ans$ 为 $s,t$ 间最短路长。否则我们重复过边可以使 $ans$ 任意 $\pm 2$，于是 $ans\in\{0,1\}$。

再判奇环。重复过环可以使 $ans$ 任意 $\pm 1$，$ans=0$。

最后判 $s,t$ 间路径奇偶性。不存在两条奇偶性不同的路径，否则它们形成一个奇环。

二分图判奇环，所有信息可以一遍 bfs 得到。
